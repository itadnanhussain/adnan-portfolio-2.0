## 📌 About

Welcome to my personal developer portfolio repository! This website showcases my software engineering journey, technical projects, skills, and experience as a Full-Stack Web Developer. Built with **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**, it emphasizes modern UI/UX architecture, performance optimization, and clean code principles.

---

## ✨ Key Features

* **🎨 Modern Responsive UI:** Fully mobile-first and responsive design crafted with Tailwind CSS.
* **⚡ High Performance:** Optimized Next.js App Router setup ensuring fast page loads and smooth client-side routing.
* **🎭 Interactive Components:** Animated background blobs, custom page preloader, and interactive UI sections.
* **💼 Project Showcases:** Clean component-driven display of featured web applications and platforms.
* **📄 Integrated Resume:** Production-ready resume served directly from [`/public/resume.pdf`](./public/resume.pdf).
